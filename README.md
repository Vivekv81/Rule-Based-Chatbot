# Rule-Based Chatbot with Natural Language Processing

A simple rule-based chatbot built using Python and NLTK.

## Features
- Responds to greetings
- Recognizes the user's name
- Answers predefined questions
- Tells a joke
- Provides basic help
- Handles unknown questions
- Ends the conversation when the user types `bye`, `exit`, or `quit`

## Technologies Used

- Python
- NLTK
- Regular Expressions
